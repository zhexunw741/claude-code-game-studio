# 部署指南（M4.4 / M4.5）

> **当前状态：尚未部署。** 没有任何公开网址，也还没有生成二维码。
> 下面的方案要等你确认**平台**和**公开内容**之后才执行。未经你同意，不购买域名，不开通付费服务。

## 发布前先确认：公开意味着什么

- `dist/` 用真实文案构建，包含六段故事节选、隐藏星文字、生日祝福（含生日信中的几句）。没有任何照片、截图或生日信全文。
- 网站一旦上线，**任何拿到链接的人都能打开页面**。页面里的 `noindex` 只是请搜索引擎不要收录，**不是访问控制**；链接里放一段随机路径也不等于加密。
- 如果需要真正的访问限制，见文末"严格私密的做法"。

## 方案 A（推荐给中国大陆收礼人）：香港地域对象存储 + 自己的域名

在阿里云 OSS 或腾讯云 COS 中选**香港**地域，开启静态网站托管，上传 `dist/`，绑定自己的域名并开启 HTTPS。

| 项目 | 说明 |
|---|---|
| 成本 | 域名每年约几十元人民币（以注册商价格为准）。本站约 165 KB，存储和流量费用通常很低。HTTPS 证书可用平台的免费证书。 |
| 实名 / 备案 | 云账号需要**实名认证**；域名注册也需要实名。香港地域服务器**不需要 ICP 备案**。中国大陆地域的服务器绑定域名必须备案，通常需要数周，生日前未必来得及。 |
| 能否由我直接部署 | 不能：需要你本人的云账号、实名和付款信息。我可以提供逐步操作，或在你提供权限后协助上传。 |
| 中国大陆可达性 | 香港节点通常可以访问，速度一般可以接受，但**不保证**；新域名在微信里打开时可能出现提示页。**需要实测。** |
| 注意 | 对象存储的默认域名通常不能直接以网页形式打开 HTML，要用自己的域名。以平台当前规定为准。 |

步骤概要：

1. 注册或登录云账号，完成实名认证；购买一个域名，并完成域名实名。
2. 在香港地域新建存储桶（Bucket），读写权限选公共读，开启"静态网站托管"，默认首页填 `index.html`。
3. 把本机 `dist/` 里的全部文件上传到存储桶根目录，保持目录结构。
4. 绑定自定义域名（按控制台提示添加 CNAME 解析），申请并启用免费 HTTPS 证书，强制 HTTPS。
5. 用中国大陆的手机流量（不连 VPN）、在微信里打开网址，按下文"上线校验"逐项检查。

## 方案 B（最快、免费、无需实名）：Cloudflare Pages

上传 `dist/` 后，会得到一个 `项目名.pages.dev` 的 HTTPS 地址。

| 项目 | 说明 |
|---|---|
| 成本 | 免费。绑定自己的域名可选。 |
| 实名 / 备案 | 不需要。 |
| 能否由我直接部署 | 需要你的 Cloudflare 账号授权（API Token）。本会话目前没有这个凭证。你也可以在网页控制台用"直接上传"把 `dist/` 拖进去。 |
| 中国大陆可达性 | **不稳定**：`pages.dev` 在中国大陆时快时慢，有时打不开。适合你在海外预览、给朋友测试；作为印在书上的正式链接**风险较高**。 |

步骤概要：

1. 在 Cloudflare 控制台进入 Workers & Pages，创建项目，选择"直接上传"（Direct Upload）。
2. 把 `dist/` 文件夹拖进去，部署完成后得到 `https://项目名.pages.dev`。
3. 以后更新：重新构建，再上传一次新的 `dist/`。

## 不推荐

- **GitHub Pages**：免费方案要求公开仓库，用真实文案构建的网站会连同文字一起公开在仓库里。
- **Vercel 默认域名**：长期有报告称 `*.vercel.app` 在中国大陆无法访问。

## 严格私密的做法（如果需要）

- **服务端口令**：在 Cloudflare Pages 上加一个 Functions 中间件做 HTTP Basic 认证，口令在服务器端校验，属于真正的访问控制。缺点是打开时要输入口令，微信内置浏览器对口令弹窗的支持需要实测。
- **邮箱验证码登录**（Cloudflare Access）：她要先收验证码才能看；在中国大陆的可用性不确定。
- **带过期时间的签名链接**：不适合印在书上，二维码过期后就会失效。

只在页面里用 JavaScript 判断口令，**不是**访问控制：查看页面源码就能看到全部文字。所以本站没有做这种"假锁"。

## 二维码与纪念册 P40（只在地址真实、测试通过后进行）

1. 用最终 HTTPS 地址生成二维码：
   - 印刷尺寸约 **32×32 mm**；
   - 黑白高对比，纠错等级 M 或 Q；
   - 四周留出至少 4 个模块的静区。
2. 导出两份文件：矢量 SVG 或 PDF 一份，供印刷；300 dpi 以上的 PNG 一份，供预览。
3. 按实际尺寸打印出来，用 2–3 部手机（含微信"扫一扫"）测试能否扫开。
4. 在纪念册排版程序中，把 v5 的 P40 二维码占位替换为真实二维码，重新导出单页 PDF 和对页 PDF，再做一次印前检查。
5. 在本文件"上线校验"表中记录版本号、地址和扫码测试结果。
