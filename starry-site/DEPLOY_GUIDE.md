## 0. 结论

- **推荐主方案：阿里云 OSS 香港地域 + 你自己的域名。** 不需要 ICP 备案（官方文档只要求中国内地地域备案）。按本站体积，存储和流量都落在官方免费额度内，托管费约等于 0 元。主要的维护工作是 HTTPS 证书：免费证书每 3 个月要手动换一次。
- **备选：Cloudflare Pages。** 免费，不需要实名和备案，证书自动续期，维护最省。缺点是在中国大陆访问不稳定，默认的 `pages.dev` 地址在微信里可能打不开。适合作为同一域名下的备用线路。
- **值得考虑：腾讯云 EdgeOne Pages。** 加速区域选"全球可用区（不含中国大陆）"时不需要备案（官方），平台自动配置证书，有免费版。但官方说明目前是"限时免费阶段"，证书是否自动续期文档里没写，需要确认。
- **无论选哪个，都要买一个自己的域名。** 二维码里印的是你的域名，以后换平台只需改域名解析，书不用重印。
- **预计费用：** 首年约等于域名费，`.cn` 约 30–40 元，`.com` 约 85–100 元（估计值，以注册商价格为准）。托管约 0 元。建议在云账号里预充 10 元左右，避免欠费停服。
- **时间：** 域名实名审核一般需要 1–3 个工作日（官方）。二维码还要在生日前放进纪念册并完成印刷，建议尽快决定平台。

## 5. 操作步骤：阿里云 OSS 香港

> 控制台的菜单名称可能随版本变化，以实际界面为准。
> **第 8 步之前，页面都不会公开。** 你说"可以公开"之前，停在第 7 步。

1. **账号：** 注册或登录阿里云，完成个人实名认证。在费用中心开启余额或可用额度预警，预充约 10 元。
2. **域名：** 搜索并购买域名。域名里不要放真实姓名，例如用一个中性的英文词。创建域名信息模板并提交实名审核。等域名状态变为正常（一般 1–3 个工作日）。
3. **想好网址：** 建议用子域名，例如 `star.你的域名`。以后二维码里印的就是 `https://star.你的域名/`。
4. **建存储桶：** 进入对象存储 OSS，创建 Bucket：
   - 地域选**中国香港**；
   - 存储类型选**标准存储**，冗余选**本地冗余**；
   - 读写权限**先选私有**；
   - Bucket 名称用无意义的字符，不要放姓名。
5. **静态页面：** 在 Bucket 的"数据管理 → 静态页面"设置：
   - 默认首页填 `index.html`；
   - 子目录首页选"不开通"；
   - 404 页可以不设，本站用哈希路由，不需要。
6. **上传：** 把私有交付包里 `网站构建_dist` 的 **6 个文件**按原目录结构上传到 Bucket 根目录：`index.html`、`favicon.svg`、`assets/`、`fonts/generated/`。
   - **只传这 6 个文件。** 源码、`story.private.json`、`STORY_CONTENT.md`、测试截图都**不要**上传。
   - 可选：给 `index.html` 设置 HTTP 头 `Cache-Control: no-cache`，以后更新时手机不会继续显示旧版本。
7. **域名和证书：**
   - 在 Bucket 的域名管理中绑定 `star.你的域名`，按提示添加 CNAME 解析。域名在同一账号下时，控制台可以自动添加。
   - 在"数字证书管理服务"申请免费证书，用 DNS 验证。签发后，在 OSS 域名管理里为这个域名配置（托管）证书。
8. **公开：** 关闭"阻止公共访问"，把 Bucket 读写权限改为**公共读**。**从这一刻起，拿到网址的人都能打开。**
9. **校验：** 按第 9 节逐项检查，全部通过后再生成二维码。
10. **日历提醒：** 证书签发后约 75 天，重新申请证书并替换（见第 10 节）。

更新网站时：重新构建 → 上传新的 6 个文件 → 删除旧的 `assets/index-*.js` 和 `.css`（文件名带哈希，新旧不会冲突）→ 再跑一次校验。

## 6. 操作步骤：腾讯云 COS 香港（与方案 A 的差别）

1. 腾讯云账号实名；在 DNSPod 或其他注册商购买域名并完成实名。
2. 创建存储桶：地域选**中国香港**（`ap-hongkong`），访问权限先选**私有读写**。
3. 上传同样的 6 个文件。
4. 在"基础配置 → 静态网站"开启，索引文档填 `index.html`。
5. 在"域名与传输管理 → 自定义源站域名"添加 `star.你的域名`，源站类型选**静态网站源站**，选择或申请证书，再按提示添加 CNAME 解析。**如果这一步要求备案，就改用方案 A 或 EdgeOne Pages。**
6. 你同意公开后，把访问权限改为**公有读私有写**，然后按第 9 节校验。
7. 注意：开启"强制 HTTPS"后，如果证书异常，访问会跳到默认域名，而默认域名不能预览（官方）。所以证书要及时续。

1. 注册 Cloudflare 账号，进入 Workers & Pages，创建 Pages 项目，选择直接上传（Upload assets）。网页拖拽上传最多 1,000 个文件，本站 6 个。

## 9. 上线校验（部署后逐项填写，不得预填）

先在电脑上运行校验脚本。它只发 GET 请求，不需要账号，不改动线上任何东西：

```bash
DIST=<私有构建的 dist 目录> npm run verify:deploy -- https://star.你的域名/
```

脚本检查以下几项：

- 首页是 HTTPS，返回 200，会以网页形式显示，而不是下载；
- 页面引用的全部资源都能取得，类型正确；
- 线上文件与本地测试过的构建逐字节一致；
- 证书剩余天数，少于 30 天会提醒。

自动化测试也可以直接对线上地址运行：

BASE_URL=https://star.你的域名/ STORY_CONTENT=<私有文案> DIST=<私有构建的 dist 目录> npm run test:e2e

## 11. 不推荐

- **GitHub Pages**：免费方案要求公开仓库，用真实文案构建的网站会连同文字一起公开在仓库里。
- **Vercel 默认域名**：长期有报告称 `*.vercel.app` 在中国大陆无法访问。
- **中国内地地域加 ICP 备案**：需要购买内地服务器，审核通常数周，生日前来不及。

## 12. 发布前先确认：公开意味着什么

- `dist/` 用真实文案构建，包含六段故事节选、隐藏星文字、生日祝福（含生日信中的几句）。没有任何照片、截图或生日信全文。
- 网站一旦上线，**任何拿到链接的人都能打开页面**。页面里的 `noindex` 只是请搜索引擎不要收录，**不是访问控制**；网址里放一段随机路径也不等于加密。
- 公共读的存储桶里**只能有这 6 个文件**：桶里的任何文件都可能被人取得。

### 严格私密的做法（如果需要）

- **服务端口令**：在 Cloudflare Pages 上加一个 Functions 中间件，做 HTTP Basic 认证。口令在服务器端校验，属于真正的访问控制。缺点是打开时要输入口令，微信内置浏览器对口令弹窗的支持需要实测。对象存储做不到这一点。
- **邮箱验证码登录**（Cloudflare Access）：她要先收验证码才能看；在中国大陆的可用性不确定。
- **带过期时间的签名链接**：不适合印在书上，二维码过期后就会失效。

只在页面里用 JavaScript 判断口令，**不是**访问控制：查看页面源码就能看到全部文字。所以本站没有做这种"假锁"。

## 13. 二维码与纪念册 P40（只在地址真实、测试通过后进行）

1. 用最终 HTTPS 地址（你自己的域名，不要用平台默认域名）生成二维码：
   - 印刷尺寸约 **32×32 mm**；
   - 黑白高对比，纠错等级 M 或 Q；
   - 四周留出至少 4 个模块的静区。
2. 导出两份文件：矢量 SVG 或 PDF 一份，供印刷；300 dpi 以上的 PNG 一份，供预览。
3. 按实际尺寸打印出来，用 2–3 部手机（含微信"扫一扫"）测试能否扫开。
4. 在纪念册排版程序中，把 v5 的 P40 二维码占位替换为真实二维码，重新导出单页 PDF 和对页 PDF，再做一次印前检查。
5. 在第 9 节表中记录版本号、地址和扫码测试结果。
