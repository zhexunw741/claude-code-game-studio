# 隐私核查（M4.4）

核查日期：2026-11-06。适用版本：0.1.0（未部署）。

## 1. 公开仓库里有什么

本仓库是 GitHub **公开仓库**。`starry-site/` 中提交的内容：

| 内容 | 是否含私人信息 |
|---|---|
| 源代码 `src/`、`scripts/`、`tests/`、配置文件 | 否。代码里没有故事文字，测试的期望值从文案文件读取。 |
| `content/story.sample.json` | 否。只有占位文字（"示例标题""这里是第一段回忆的示例文字"等）。 |
| `public/favicon.svg` | 否。一颗原创的四角星图标。 |
| README、TEST_REPORT、PRIVACY_CHECK、DEPLOY_GUIDE | 否。只描述程序、测试数字和流程，不引用故事文字。 |

`.gitignore` 排除的内容：

- `content/story.private.json` 等私人文案；
- `dist/`，即构建产物；
- `public/fonts/generated/`，由真实文案生成的字体子集；
- `STORY_CONTENT.md`，即全站文案清单；
- `test-output/`，即测试截图与结果。

**提交前扫描**：把真实文案中的每一句（全部故事文字与日期），连同若干私人关键词，与本次提交的全部新增内容逐一比对，结果为 **0 处命中**。

## 2. 真实文案和私人文件放在哪里

- 真实文案、文案清单、测试截图，以及用真实文案构建的 `dist/`，都放在当前会话的私有工作区，不在仓库里，并已经打包直接发给你。
- 这个云端工作区会在会话结束后被回收。请自己保存好那个私有压缩包。

## 3. 用真实文案构建出的网站包含什么

| 包含 | 不包含 |
|---|---|
| 网站标题、两句新写的引导语、界面文字 | 任何照片（合照、花束等） |
| 六颗星的标题、日期和节选文字（来自原稿 P05–P37 与 P40） | 聊天截图 |
| 隐藏星的标题与三段文字（原稿 P14、P15、P40） | 生日信全文 |
| 生日章节：任务书中你给出的那句话，以及生日信 P38 中的约 7 句 | 纪念册 PDF、原稿全文 |
| 结尾：P40 与衔接稿中的句子 | 任何真实姓名 |

- 网站**不收集任何数据**：没有统计、埋点、Cookie、登录，也不请求外部网址（测试中实测外部请求为 0）。
- "已点亮"状态只保存在她手机当前浏览器标签页里（sessionStorage），不会上传。
- 网站不申请摄像头、麦克风、定位、通知等任何权限。

## 4. 部署前需要你批准的事项

1. **是否把上面第 3 节左列的文字放到网上。** 上线后，任何拿到链接的人都能看到；`noindex` 只能减少搜索引擎收录，不是隐私保护。
2. **部署平台**，见 DEPLOY_GUIDE.md。方案 A 需要你的实名云账号和域名，方案 B 免费但在中国大陆可能不稳定。
3. **两句新写的文字**：开场引导语和星图提示，见私有包里的 `STORY_CONTENT.md`。
4. **生日主句用哪个版本**：任务书里的原话，还是生日信 P38 的原文写法。
5. **网页上是否放照片**：目前一张都没有放。如果要放，需要你逐张指定，并确认可以公开。
