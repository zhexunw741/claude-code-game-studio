# 《幸好，故事还在继续》生日纪念册 · 第七版排版

成品 125×176mm，40 页。文学小说风；封面浅蓝天空与鲸，内页奶油白，午夜蓝收尾。
本版已确认的方向：**同一片海，从清晨到夜晚**；封面采用**竖排书名**。

> 这是可审阅的版式稿，不是印刷终稿。原正文、照片、聊天截图、初见插画和生日信都还没有拿到，书中对应位置全部是占位。

## 设计思路

- **一天的天空作为全书节奏。** 封面海景里没有鲸的那一角，在书里反复出现，并随时间变化：
  - P02–P03：清晨的海横跨两页。
  - 三个篇章页：同一扇圆窗，依次是清晨、午后、傍晚。
  - P39 后记：暮色。后记里"留下一扇回望此刻的窗"正好对应这扇窗。
  - P40：鲸游进夜空，深蓝结尾因此有了来由。
- **装饰是"事件"，不是每页都贴。** 柳枝、枫枝改为单色（灰绿、香槟沙色），像植物版画，不透明度 0.7，只放在篇章页和较空的照片页的外侧角落，不靠近文字、照片和人物。P06–P07 周围不加任何装饰。
- **排版：**
  - 书名竖排。
  - 正文思源宋体（Noto Serif SC）12pt，行距 21pt，段首缩进两字，场景转换用星点分隔。
  - 页眉：左页书名、右页章名；页码居中，使用 Cormorant Garamond 等高数字。
  - 照片做成白边相纸，配图号和图注；聊天截图用单张竖幅，图注竖排。
- **固定页位：**
  - P06（左）–P07（右）：同一幅连续跨页插画位，画幅 250×143mm，中间 12mm 是书沟，人物面部要避开。
  - P38：生日信整页信笺，加邮戳和横格。
  - P39：ChatGPT 署名后记，12pt/21pt，保持单页。
  - P40：32mm 二维码位，不可扫描。

## 缺项（需要你补齐）

1. 原 40 页正文，以及原来的页序（排版以它为准）
2. P38 生日信全文：放入后先检查篇幅，不删节；信笺横格约能容纳 20 字 × 15 行，超出时去掉横格或加长信纸，不缩小字号
3. 聊天截图原图：需在实际打印尺寸下确认字迹能看清
4. 花束和你们两人的原照：按实际摆放尺寸检查分辨率，目标 300ppi，不插值放大
5. 台球厅初见的原插画：连续跨页，250×143mm，出血另加
6. 旧后记（可选）：现 P39 是本轮新拟版本
7. 星空网站的最终 HTTPS 链接：确认后生成真实二维码替换 P40，以实际尺寸打印并扫码验证
8. 封面插画的高分辨率版本（见下方分辨率表）

## 印刷前还需处理

- 目前是 RGB、普通 PDF，没有做 PDF/X 认证，不能直接下单。
- 纸张、装订方式、出血要求、书沟补偿、色彩配置，都以印厂要求和实物打样为准。
- 香槟金只是普通颜色，不是金属墨或烫金；如果要烫金，需要另出专色版。
- 已附 `输出/幸好_纪念册_v7_40页_出血3mm.pdf`：四边 3mm 出血，总画幅 131×182mm，PDF 里已写好 125×176mm 的 TrimBox。它是由源文件按出血重新排出来的，不是把净尺寸稿放大。印厂确认出血规格后再定稿。
- 字体以 TrueType 子集嵌入 PDF。两款字体（思源宋体 / Noto Serif SC、Cormorant Garamond）都是 SIL Open Font License，可以免费用于印刷。
- 对页 PDF 只用来看翻书效果，书沟处的阴影只出现在对页版里，它不是印厂拼版文件。
- 去掉全部占位提示、确认素材齐备之后，再导出印刷终稿。

## 文件结构与重建

```
纪念册/
├── 源文件/
│   ├── build.py         页位表 PAGES 与全部页型模板（毫米 / 磅）；改版主要改这里
│   ├── render.js        Playwright 输出 PDF 与逐页预览
│   ├── fix_boxes.py     把页面框校正为精确毫米尺寸，写入 TrimBox / BleedBox
│   ├── prep_assets.py   由原图生成裁切、调色和单色枝叶（输出与"处理后"逐字节一致）
│   ├── contact.py       生成 40 页总览图
│   └── 生成全部.sh      一键重建
├── 素材/原图        三张原创插画（未改动）
├── 素材/处理后      排版实际引用的图片
├── 字体/            本地静态字体，离线可重建
└── 输出/            PDF、HTML、逐页预览（preview/）、总览图、逐页状态.json
```

重建命令：`cd 源文件 && bash 生成全部.sh`

依赖：python3（Pillow、numpy、pypdf），node + playwright（chromium）。

补齐原稿后的做法：

- 在 `build.py` 的 `PAGES` 里改页型、调整顺序。
- 正文放进 `text` / `text_first` 页型，替换灰条。
- 照片用 `<img>` 替换 `photo()` 占位，保持白边相纸样式。
- 生日信放进 `t_letter`。
