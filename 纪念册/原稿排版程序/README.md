# 原稿排版程序（正式版）

用这套程序把原稿排成 40 页 B6 纪念册（125×176mm，正文 10pt / 行距 16pt，原稿一页对应成书一页）。

> **隐私规则：** 本仓库是公开仓库。原稿全文、生日信、照片、聊天截图、私有排版配置，以及由它们生成的 PDF 和预览图，**一律不提交**。`纪念册/.gitignore` 已经排除了这些目录。程序本身不包含任何正文和图片。

## 私有文件放在哪里（不入库）

```
纪念册/
├── 原始素材/                 ← 私有，已被 .gitignore 排除
│   ├── 正文/原稿.txt          原稿全文，含 P01–P40 页码标记
│   ├── 正文/P39_后记_*.txt     已确认的特别后记原文（缺失时 P39 只排标题和占位）
│   ├── 正文/P40_衔接稿.txt     经确认的 P40 替换稿（可选）
│   ├── 图片/…                 照片、截图、插画原文件
│   └── 排版配置.json          图片位置、裁切、图注、装饰、P39 标题
├── 原稿输出/                 ← 私有，生成的 HTML / PDF / 预览
├── 素材/处理后/  字体/        ← 公开：装饰图与字体（与 v7 共用）
└── 原稿排版程序/              ← 本目录
```

## 排版配置格式（示例值，非真实内容）

```json
{
 "images": {"photoA": "图片文件名.jpg"},
 "placements": {"12": {"img": "photoA", "w": 60, "crop": [0, 100, 900, 800], "cap": "图注"},
                "30": {"img": null, "w": 60, "h": 35, "label": "照片位"}},
 "ornaments": {"10": "birds", "22": "maple"},
 "end_marks": [10, 22],
 "p39": {"label": "后记", "title": "标题", "file": "正文/P39_后记.txt", "size": 10, "lead": 14.5, "width": 100},
 "page_overrides": {"40": "正文/P40_替换稿.txt"},
 "corrections": [{"page": 12, "from": "原句（整段）", "to": "订正后的整段"}]
}
```

- `crop`：原图的像素区域 `[x0, y0, x1, y1]`，`null` 表示整张；`w` 是印刷宽度（mm）。
- `img` 为 `null` 时只排预留图位（占位框），不放任何替代图片。
- `corrections`：作者确认的文字订正。原稿文件保持不动，排版时套用订正；每条规则必须恰好命中该页的一个标题或一整段，否则中止，避免误改。
- 替换稿每行一段。写成 `[…二维码…]` 的那一行，会排成 32mm 的二维码占位。
- P39 后记原文每行一段：`**…**` 是强调句，以 `——` 开头的是署名行，`*…*` 是落款行。标记符号本身不会排出来。
  P39 的字号、行距、栏宽可以单独设置，用来在单页内完整容纳原文、不删减。

## 生成步骤

```bash
cd 纪念册
python3 原稿排版程序/parse_text.py 原始素材/正文/原稿.txt 原始素材/正文/逐页切分.json
python3 原稿排版程序/build_book.py 原始素材/正文/逐页切分.json 原稿输出 --config 原始素材/排版配置.json
node 原稿排版程序/render_check.js 原稿输出 pdf          # 逐页报告溢出与余量，输出 single.pdf / spread.pdf
python3 源文件/fix_boxes.py 原稿输出/single.pdf 125 176
python3 源文件/fix_boxes.py 原稿输出/spread.pdf 250 176
```

`render_check.js` 会报告每页"溢出 / 余量"。任何一页出现溢出，都要先处理，不能缩小字号了事。

## 交付前检查清单

- 40 页，成品尺寸 125×176mm；P02–P40 页码逐页正确（P01 扉页不印页码）。
- 除经确认替换的页面外，各页正文与原稿逐段一致（用 `pdftotext` 逐页比对）。
- P06（左）–P07（右）为同一幅连续跨页插画，书沟两侧像素连续。
- P38 生日信全文完整；P39 只用已确认的后记原文；P40 保留二维码占位，链接确认前不生成可扫描的码。
- 字体以 TrueType 子集嵌入，PDF 里没有 Type 3 字体。
